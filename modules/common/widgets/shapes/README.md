# Morphing shapes for QML

This directory contains a QML-compatible JavaScript port of [Knugel's TypeScript port](https://github.com/Knugel/rounded-polygon-ts) of AndroidX's shape library, along with the 35 [Material Design shapes](https://m3.material.io/styles/shape/overview-principles#579dd4ba-39f3-4e60-bd9b-1d97ed6ef1bf).

### Example

Run the example with Quickshell's runner:

```sh
qs -p example.qml
```

https://github.com/user-attachments/assets/142cdd86-2a30-4c77-a9ce-e234b6d0d77e

### Usage

The code is intended for Quickshell QML. It is not packaged as a standalone library, and its API may change. See the adjacent `LICENSE` for terms.
